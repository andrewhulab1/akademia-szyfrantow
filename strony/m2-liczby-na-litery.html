Misja 2: Liczby na literyMission 2: Numbers to letters

Cele lekcji / Learning objectives
  • Potrafię zamienić liczby 1–26 na litery (A = 1). I can change the numbers 1–26 into letters (A = 1).
  • Potrafię znaleźć liczby ukryte w godzinach, obliczeniach i obrazkach. I can find numbers hidden in times, calculations and pictures.
  • Potrafię użyć przesuniętego klucza, gdy 1 nie oznacza A. I can use an offset key when 1 does not mean A.
klucz / keyszyfr alfanumeryczny / alphanumeric cipherprzesunięcie / offsetróżnica / difference

Gdy widzisz liczby od 1 do 26, sprawdź najpierw najprostszy klucz: A = 1, B = 2 … Z = 26. GCHQ chowa te liczby w godzinach na zegarach, w wynikach odejmowania, a nawet w nutach.

When you see numbers from 1 to 26, first try the simplest key: A = 1, B = 2 … Z = 26. GCHQ hides these numbers in clock times, in the results of subtractions, and even in musical notes.

Liczba większa niż 26? To znak, że trzeba coś policzyć albo że klucz jest inny.

A number bigger than 26? That is a sign you need to calculate something, or that the key is different.

💡 Zapamiętaj! Klucz jest jak numeracja wieszaków w szatni: każda liczba należy do jednej litery. Gdy ktoś przesunie numerację, A może mieć zupełnie inny numer.
Remember! A key is like the numbers on cloakroom pegs: each number belongs to one letter. If someone moves the numbering, A can have a completely different number.

Ćwiczenia / Practice

ZADANIE / TASK 1

Rozszyfruj: 19 14 15 23

Decode: 19 14 15 23

Podpowiedź / Hint

19 = S. Użyj tabeli powyżej.

19 = S. Use the table above.

ZADANIE / TASK 2

Szpieg zostawił kartkę z czterema godzinami. Liczą się tylko pełne godziny.

A spy left a note showing four times. Only the hours count.

07:00 · 09:00 · 06:00 · 20:00

Podpowiedź / Hint

20:00 to godzina 20, czyli T.

20:00 is hour 20, which is T.

ZADANIE / TASK 3

Uwaga: w tym kluczu 1 = C. Rozszyfruj: 8 13 23

Careful: in this key 1 = C. Decode: 8 13 23

Podpowiedź / Hint

Napisz alfabet od C: C = 1, D = 2, E = 3 … Wtedy A = 25, a B = 26.

Write the alphabet starting at C: C = 1, D = 2, E = 3 … Then A = 25 and B = 26.

ZADANIE / TASK 4

Najpierw policz różnice, potem zamień je na litery (A = 1).

First work out the differences, then turn them into letters (A = 1).

20 − 18 · 30 − 15 · 50 − 26

Podpowiedź / Hint

20 − 18 = 2, czyli B.

20 − 18 = 2, which is B.
