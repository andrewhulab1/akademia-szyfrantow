Misja 1: Pierwsze literyMission 1: First letters

Cele lekcji / Learning objectives
  • Potrafię odczytać ukrytą wiadomość z pierwszych liter słów. I can read a hidden message from the first letters of words.
  • Potrafię rozpoznać słowa-sygnały, takie jak initially czy leading. I can recognise signal words such as initially or leading.
  • Potrafię sprawdzić również ostatnie litery. I can also check the last letters.
akrostych / acrosticpierwsza litera / initial letterostatnia litera / final lettersłowo-sygnał / signal word

To najczęstsza sztuczka w GCHQ Christmas Challenge — pojawiła się w każdej edycji od 2021 do 2025 roku. Czasem cała odpowiedź jest ukryta w pierwszych literach samego pytania. Dlatego zawsze zaczynaj od tego sprawdzenia: to zajmuje dziesięć sekund.

This is the most common trick in the GCHQ Christmas Challenge — it appeared in every edition from 2021 to 2025. Sometimes the whole answer is hidden in the first letters of the question itself. So always start with this check: it takes ten seconds.

Przykład / Example

Santa Never Opens Windows → SNOW

Słowa-sygnały / Signal words

Autorzy zagadek często podpowiadają, gdzie patrzeć. Te angielskie słowa zwykle oznaczają pierwsze albo ostatnie litery:

Puzzle setters often hint where to look. These English words usually point to the first or the last letters:

Pierwsze litery / First lettersOstatnie litery / Last letters
first, initially, primarily, leading, heads, starts, opening, capitallast, finally, ends, tails, closing, behind
💡 Zapamiętaj! Pierwsze litery są jak lista obecności: czytasz tylko początek każdej linijki i od razu widzisz, kto przyszedł.
Remember! First letters are like a class register: you read only the start of each line and see at once who is there.

Ćwiczenia / Practice

ZADANIE / TASK 1

Odczytaj pierwsze litery: Cats Only Ate Tuna.

Read the first letters: Cats Only Ate Tuna.

Podpowiedź / Hint

Weź pierwszą literę każdego słowa.

Take the first letter of each word.

ZADANIE / TASK 2

Jakie słowo ukryto w tym wierszu?

Which word is hidden in this poem?

Snow falls softly
Trees are white
All is quiet
Robins sing

Podpowiedź / Hint

Spójrz na początek każdej linijki, z góry na dół.

Look at the start of each line, from top to bottom.

ZADANIE / TASK 3

Tym razem odczytaj ostatnie litery: cub, tree, owl, ball.

This time read the last letters: cub, tree, owl, ball.

Podpowiedź / Hint

Ostatnia litera słowa cub to B.

The last letter of cub is B.

ZADANIE / TASK 4

Słowo-sygnał podpowiada, co robić: „Primarily, notice: Happy Owls Like Long Yawns.” Jakie słowo ukryto w ostatnich pięciu słowach?

The signal word tells you what to do: “Primarily, notice: Happy Owls Like Long Yawns.” Which word is hidden in the last five words?

Podpowiedź / Hint

Primarily zaczyna się jak primary — pierwszy. Weź pierwsze litery.

Primarily starts like primary — first. Take the first letters.
