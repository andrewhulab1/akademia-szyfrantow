Misja 5: System binarnyMission 5: Binary

Cele lekcji / Learning objectives
  • Potrafię zamienić liczbę binarną na dziesiętną, używając wag 16, 8, 4, 2, 1. I can convert a binary number to a decimal number using the place values 16, 8, 4, 2, 1.
  • Potrafię odczytać litery zapisane binarnie (A = 1). I can read letters written in binary (A = 1).
  • Potrafię rozpoznać zapis binarny ukryty w obrazkach: lampkach, kropkach, nutach. I can spot binary hidden in pictures: lights, dots or musical notes.
system binarny / binarybit / bitwaga pozycji / place valuesystem dziesiętny / decimal

Komputer posługuje się tylko dwoma stanami: włączone (1) i wyłączone (0). Pięć bitów wystarczy na liczby od 1 do 31, a więc na cały alfabet. Każda pozycja ma swoją wagę: 16, 8, 4, 2, 1. Dodajesz wagi tylko tam, gdzie stoi 1.

A computer uses only two states: on (1) and off (0). Five bits are enough for the numbers 1 to 31, and therefore for the whole alphabet. Each position has its own place value: 16, 8, 4, 2, 1. You add the place values only where there is a 1.

Włącz lampki / Switch on the lights

Liczba / Number: 0 · Litera / Letter: —

10011 → 16 + 2 + 1 = 19 → S

💡 Zapamiętaj! System binarny to rząd włączników światła: włączony to 1, wyłączony to 0. Dodajesz tylko te, które świecą.
Remember! Binary is a row of light switches: on is 1, off is 0. You add up only the ones that are lit.

Ćwiczenia / Practice

ZADANIE / TASK 1

Rozszyfruj (A = 1): 01001 00011 00101

Decode (A = 1): 01001 00011 00101

Podpowiedź / Hint

01001 = 8 + 1 = 9, czyli I.

01001 = 8 + 1 = 9, which is I.

ZADANIE / TASK 2

Każdy zestaw pięciu lampek to jedna litera. Świecąca lampka = 1.

Each set of five lights is one letter. A lit light = 1.

Podpowiedź / Hint

Pierwszy zestaw: 1 0 0 1 0 = 16 + 2 = 18, czyli R.

First set: 1 0 0 1 0 = 16 + 2 = 18, which is R.

ZADANIE / TASK 3

Jaką liczbą dziesiętną jest 11010?

What decimal number is 11010?

Podpowiedź / Hint

16 + 8 + 2.

16 + 8 + 2.
