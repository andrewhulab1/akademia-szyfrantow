Here are all the techniques that appeared in the GCHQ Christmas Challenge from 2021 to 2025 — in one place. Each has a short description of how to recognise it, our own example and a link to the mission where you learn it.

First letters (acrostic)		Słowa-sygnały: first, initially, leading. Sprawdzaj zawsze jako pierwsze.

Liczby na litery (A = 1)
Numbers to letters (A = 1)		Liczby 1–26, godziny, wyniki działań.

Przesunięty klucz liczbowy
Offset number key		Liczby nie dają sensu przy A = 1; szukaj podpowiedzi typu „2 = H”.
Numbers make no sense with A = 1; look for a hint such as “2 = H”.		1 = C: 8 13 23 → JOY2025Numbers to letters

System binarny
Binary		Tylko dwa symbole: 0/1, ●/○, czarne/białe nuty.
Only two symbols: 0/1, ●/○, black/white notes.		10011 → 19 → S2023, 2024Binary
Alfabet Morse’a
Morse code		Kropki i kreski, czasem zapisane od tyłu.
Dots and dashes, sometimes written backwards.		... --- ... → SOS2024, 2025Morse code
Szyfr płotkowy
Rail fence cipher		Wszystkie litery są właściwe, ale pomieszane.

Szyfr masoński (pigpen)
Pigpen cipher		Kształty z siatki i litery X, czasem z kropką.
Shapes from a grid and an X, sometimes with a dot.		⊔ ⊓ …2025Dla chętnych / Extra

Backwards text		Słowa-sygnały: reversed, backwards, mirror.
