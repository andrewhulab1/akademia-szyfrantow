Misja 6: Alfabet Morse’aMission 6: Morse code

Cele lekcji / Learning objectives
  • Potrafię odczytać alfabet Morse’a z tabeli. I can read Morse code using a table.
  • Potrafię rozpoznać alfabet Morse’a w kropkach, kreskach, światłach i dźwiękach. I can spot Morse code in dots, dashes, lights and sounds.
  • Potrafię odczytać alfabet Morse’a zapisany od tyłu. I can read Morse code written backwards.
kropka / dotkreska / dashodstęp / spaceod tyłu / backwards / reversed

Alfabet Morse’a zamienia każdą literę w krótkie (kropka) i długie (kreska) sygnały. Odstęp oddziela litery, a ukośnik / oddziela słowa. GCHQ chowało go w trasie sań Mikołaja, w ramce kartki, a w 2025 roku nawet zapisało go od tyłu.

Morse code turns each letter into short (dot) and long (dash) signals. A space separates letters and a slash / separates words. GCHQ hid it in the route of Santa’s sleigh, in the border of a card, and in 2025 even wrote it backwards.

G --.H ....I ..J .---K -.-L .-..

S ...T -U ..-V ...-W .--X -..-
Y -.--Z --..

Chcesz usłyszeć alfabet Morse’a? W skrzynce narzędzi jest przycisk ▶. Want to hear Morse code? There is a ▶ button in the toolbox.

💡 Zapamiętaj! Alfabet Morse’a jest jak pukanie w ścianę umówionym rytmem: krótko i długo. Gdy zapis wygląda dziwnie, przeczytaj go od końca.
Remember! Morse code is like knocking on a wall in an agreed rhythm: short and long. If the code looks strange, read it from the end.

Ćwiczenia / Practice

ZADANIE / TASK 1

Rozszyfruj: -.-. .- -.- .

Decode: -.-. .- -.- .

Podpowiedź / Hint

-.-. to C.

-.-. is C.

ZADANIE / TASK 2

Rozszyfruj: ... -.- .- - .

Decode: ... -.- .- - .

Podpowiedź / Hint

... to S, a - to T.

... is S and - is T.

ZADANIE / TASK 3

Ten zapis Morse’a jest odwrócony: .-.. ..-. .

This Morse code was written backwards: .-.. ..-. .

Podpowiedź / Hint

Odwróć cały zapis znak po znaku (albo użyj przycisku „Morse od tyłu” w skrzynce narzędzi).

Reverse the whole line symbol by symbol (or use the “Reversed Morse” button in the toolbox).
